# About Maharaj Downloader

**Maharaj Downloader** — a free download manager for personal use.

- Prepared by **Sasanka Boruah (VU3INI)**
- Contact: **hamvu3ini@gmail.com**

## Built on open source

Maharaj Downloader is built on **Mister Download Manager** by Ahmed Nefzaoui, which is free and open-source software under the GNU General Public License, version 3 or later. Maharaj Downloader is distributed under the same licence; its source code is the upstream project's source with the changes listed in the `SOURCE` folder of the distribution.

It also includes yt-dlp, FFmpeg, gallery-dl and 7-Zip (see [The included helpers](05-offline-helpers.md)), and libraries such as egui, Tokio, rustls and librqbit, each under its own licence (see the `LICENSES` folder).
