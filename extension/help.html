The Maharaj Downloader browser extension

Maharaj Downloader · offline help

The free Maharaj Downloader extension hands the downloads you start in your browser to Maharaj Downloader, puts a Download video button over videos, and adds Download with Maharaj Downloader to the right-click menu of links, pictures, videos and sound. It comes with Maharaj Downloader, so it installs offline, from the extension folder of the program.

The extension talks to Maharaj Downloader through its browser integration, which the setup turns on when Set up browser integration is ticked (it is by default).

Add it to Chrome, Edge, Brave, Opera or Vivaldi

  1. Open the browser's extensions page: type chrome://extensions (Edge: edge://extensions, Brave: brave://extensions, Opera: opera://extensions, Vivaldi: vivaldi://extensions) in the address bar and press Enter.
  2. Turn on Developer mode (top right in Chrome; on the left in Edge).
  3. Click Load unpacked and choose the folder extension\chromium in Maharaj Downloader's folder — installed: %LOCALAPPDATA%\Programs\Maharaj Downloader\extension\chromium (paste that into the folder box).
  4. Maharaj Downloader appears in the list with its logo. Click the puzzle-piece button on the toolbar and pin it, so its button stays in sight.
  5. Click the button: it should say Connected to Maharaj Downloader.

Keep the chromium folder where it is: the browser loads the extension from it at every start. When Chrome shows a note about extensions in developer mode, you can close it; the extension keeps working.

Add it to Firefox

Firefox installs for good only extensions signed by Mozilla. The file extension\maharaj-downloader-firefox.xpi is the Firefox extension, not yet signed:

  • Firefox Developer Edition, Nightly or ESR: open about:config, set xpinstall.signatures.required to false, then open about:addons, click the gear button, Install Add-on From File..., and choose the .xpi.
  • Firefox (regular): open about:debugging#/runtime/this-firefox, click Load Temporary Add-on... and choose the .xpi. Firefox removes it again when it closes.

To install it for good in regular Firefox, the author signs it once on addons.mozilla.org as a self-distributed (unlisted) add-on; a signed .xpi then installs by dragging it onto Firefox.

Use it

  • Click a download link: the file goes to Maharaj Downloader's Download File Info instead of the browser's downloads. Hold Alt while clicking to leave it to the browser.
  • Download video: point at a video on a page; click the button on its edge. Its arrow hides it on one video or one site.
  • Right-click a link, picture, video or sound: Download with Maharaj Downloader. On selected text or a page: download its links.
  • The toolbar button shows whether the browser reaches Maharaj Downloader, pauses catching downloads, leaves one site to the browser, lists the media the page loaded, and opens Maharaj Downloader or its Options.

If it says it isn't connected

  • Check Maharaj Downloader is installed with Set up browser integration ticked (run the setup again to tick it), and running.
  • The portable copy can't connect to browsers: install Maharaj Downloader with the setup.
  • Reload the extension (the round arrow on its card in the extensions page) after installing Maharaj Downloader.

The extension's own help page (its toolbar button → Help) explains each message.

Privacy

The extension sends the download's address, its page, and the cookies the site set for it to Maharaj Downloader on your own computer, so that it can download what you asked for. Nothing goes anywhere else.

If the browser and Maharaj Downloader aren't connected

← Back to docs index

When the browser can't hand a download to Maharaj Downloader, it keeps the download itself, so nothing is lost. The extension's toolbar button then shows a red !. Click it to see what's wrong, then How to fix it brings you to the matching section below.

To check Maharaj Downloader's side, open Options → General in Maharaj Downloader and click Test browser integration.... It checks that browser integration is on, that this is the installed copy, that the browsers can find Maharaj Downloader, and which browsers' extension has connected; How to fix it opens the section for the first that fails.

Maharaj Downloader isn't installed, or browser integration isn't set up

The browser can't find the small helper program it talks to. It is registered when Maharaj Downloader is installed.

  1. Install Maharaj Downloader with the setup from the download page, and keep Set up browser integration ticked.
  2. Already installed? Open Maharaj Downloader, then Options → General → Test browser integration, and click Set it up if it offers to.
  3. The portable copy can't be connected: it writes nothing outside its own folder. Use the installed copy for browser integration. See Portable mode.
  4. On Linux and macOS, Maharaj Downloader sets browser integration up itself each time it starts: start Maharaj Downloader once. Test browser integration says what went wrong if it couldn't, such as The helper program the browsers start is missing: Set it up puts it back.
  5. Restart the browser after setting it up.
  6. Zen, Helium, Brave Origin or another browser built on Firefox or Chromium, as your only browser on Linux or macOS? Older versions of Maharaj Downloader set browser integration up only for the browsers they knew; the current one also knows Brave Origin and the Beta, Dev and Nightly versions of Brave, Chrome and Edge. Update Maharaj Downloader and start it once.
  7. The AppImage on Linux: the AppImage's files are gone once it quits, so Maharaj Downloader keeps a copy of its helper program in its data folder (~/.local/share/misterdownloadmanager/browser-host) and points the browsers there. Start Maharaj Downloader once after moving or renaming the AppImage, or after an AppImage manager (Gear Lever, AppImageLauncher and the like) moved it, so the helper knows where to start it from.
  8. Zen on Windows: Zen 1.21.15b and later have a bug of their own that keeps add-ons from reaching their helper program (zen-browser/desktop#15432), with any add-on that uses one. Until Zen fixes it, Zen 1.21.14b works.

Maharaj Downloader didn't start in time

When Maharaj Downloader isn't running, the browser starts it for each download and waits for it. It waited about 20 seconds this time and gave up.

  • Start Maharaj Downloader yourself and try the download again.
  • A first start, a slow disk, or an antivirus scanning Maharaj Downloader can take that long. Next time it is usually quick.
  • With a VPN or proxy program, allow connections to 127.0.0.1 (your own computer): the browser's helper reaches Maharaj Downloader through one.
  • If Maharaj Downloader never opens, see The setup or Maharaj Downloader won't start.

The connection to Maharaj Downloader failed

The browser started Maharaj Downloader's helper, but it stopped before answering. Security software is the usual cause.

  • Allow MaharajDownloader-nmhost.exe (in Maharaj Downloader's folder) in your antivirus or anti-malware program.
  • Reinstall Maharaj Downloader to restore its files.
  • On Linux, with Firefox or Chromium installed as a Snap, see Flatpak and Snap browsers.
  • Uninstalled Maharaj Downloader on Linux? The .deb and .rpm take their browser files with them; the AppImage's and the tar.gz's stay in your home folder: remove them, and the extension too.

Maharaj Downloader doesn't accept this copy of the extension

Maharaj Downloader's helper serves only its own extension. The browser says this copy isn't one it knows.

  • Maharaj Downloader 0.2.x with the extension from the Chrome Web Store? The store's copy needs a newer Maharaj Downloader: 0.2.x knows only the copy in its own folder. Update Maharaj Downloader with Help → Check for updates.... Until then, remove the store's copy and load the one in Maharaj Downloader's folder instead (extension\chromium, see Browser integration).
  • Two copies installed? Open the browser's extensions page (chrome://extensions, edge://extensions, brave://extensions) and keep only one Maharaj Downloader.
  • A copy from elsewhere? Remove it and add the extension as Maharaj Downloader's Add Maharaj Downloader to your browser window shows (see Browser integration).
  • An older Maharaj Downloader? Update Maharaj Downloader: a newer extension may have an ID an old helper doesn't know.

The extension is newer than Maharaj Downloader

Downloads still work, but some of the extension's features need a newer Maharaj Downloader. Update it with Help → Check for updates... in Maharaj Downloader.

If Maharaj Downloader says it's up to date, there's nothing for you to do. The extension updates by itself through its store and can get ahead of the app for a while. Everything keeps working, and the message goes away with the next version of Maharaj Downloader.

A download's details were too large

A download carries its site's cookies (and a form's data) to Maharaj Downloader. A few sites set so many that together they exceed what Maharaj Downloader accepts from the browser (1 MB). The browser kept this one. Signing out and back in to the site usually trims them.

Downloads stay with the browser although Maharaj Downloader is connected

The extension is connected, but Maharaj Downloader's own settings leave this download to the browser. Check, in Maharaj Downloader:

  1. Options → General → Use advanced browser integration is on, and your browser is ticked under Capture downloads from the following browsers.
  2. The file's type is listed in Options → File types.
  3. The site isn't in Don't start downloading automatically from the following sites, nor the address in Don't start downloading automatically from the following addresses.
  4. The file isn't smaller than Don't take files smaller than in Options → File types.

Also check the extension's toolbar button: with Take downloads from this browser off, everything stays with the browser.

The browser opens PDFs and music instead of sending them

Maharaj Downloader also takes the file types the browser would show or play itself (a PDF, an MP3), when they're listed in Options → File types and Also take files the browser would open is ticked in Options → General → Keys.... This needs a Chromium browser (Chrome, Edge, Brave, Opera, Vivaldi) version 128 or later, or Firefox. Sites in Maharaj Downloader's excluded sites keep opening them in the browser. Hold Alt while clicking a link to leave it to the browser: Firefox then opens it, while Chromium browsers download it themselves (Alt+click is their own "download link").

No Download video button on YouTube in Chrome, Edge or Brave

The copy of the extension from the Chrome Web Store showed no Download video button on YouTube before version 0.5.1. From 0.5.1 it shows it. Your browser updates extensions by itself; to get it sooner, open its extensions page and update them there.

You can always save a video without the button: in Maharaj Downloader, open Tasks → Download video from a page and paste the video's address.

The extension can't read this site

In Chrome, Edge and Brave you can limit an extension to some sites (right-click its toolbar button → This can read and change site data). On a site it may not read, the extension can't pass your sign-in on, so it leaves the download to the browser. Choose On all sites to let Maharaj Downloader take downloads everywhere.

Firefox forgets the extension after a restart

An add-on loaded with Load Temporary Add-on (from about:debugging) is removed when Firefox closes. Remove it and install the add-on from its page on addons.mozilla.org instead: Firefox keeps that one, and updates it.

Linux: Flatpak and Snap browsers

Browsers installed as a Flatpak or a Snap run in a sandbox, which decides whether they can reach Maharaj Downloader.

  • Firefox as a Snap (Ubuntu's own Firefox) reaches Maharaj Downloader through the desktop, which reads the browser files in your home folder and those the .deb or .rpm installs for everyone. The first time the extension calls Maharaj Downloader, the desktop asks Allow Firefox to start WebExtension backend? for Maharaj Downloader: choose Allow. After Don't allow, the extension says the connection failed and the desktop doesn't ask again; to be asked again, run this in a terminal, then use the extension again:

gdbus call --session --dest org.freedesktop.impl.portal.PermissionStore --object-path /org/freedesktop/impl/portal/PermissionStore --method org.freedesktop.impl.portal.PermissionStore.Delete webextensions com.misterdownloadmanager.host - Chromium as a Snap (Ubuntu's Chromium) starts Maharaj Downloader's helper inside its sandbox, where it can't reach Maharaj Downloader, so Maharaj Downloader doesn't list it in Add Maharaj Downloader to your browser. Use Firefox, or Google Chrome from its own .deb. - Flatpak browsers (such as Zen's app.zen_browser.zen) can't start Maharaj Downloader's helper, so Maharaj Downloader doesn't list them either. Install the browser from your distribution's packages (or the browser maker's own .deb, .rpm, tarball or AppImage) to use browser integration.
