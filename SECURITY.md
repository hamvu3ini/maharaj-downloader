# Security

Please report a security problem privately, by email to **hamvu3ini@gmail.com** (or GitHub's
**Report a vulnerability** form on this repository), not in a public issue. Say what you found, how to
reproduce it, and which version you use (**Help → About**).

Only the latest release gets security fixes. Problems in the parts Maharaj Downloader is built on can
also be reported to [Mister Download Manager](https://github.com/anefzaoui/misterdownloadmanager/security)
and to the helpers' own projects (yt-dlp, FFmpeg, gallery-dl, 7-Zip).
